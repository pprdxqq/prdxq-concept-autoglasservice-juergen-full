# Autoglasservice Jürgen Full — PRDXQ Concept

An independent redesign concept for the public listing **Autoglasservice: Jürgen Full**, Gottfried-Keller-Str. 21, 65451 Kelsterbach.

> This concept was created by PRDXQ without a commission or endorsement from the business. It is not an official business website.

## Evidence and content limits

The city of Kelsterbach's business directory lists the business category, address, phone numbers and email address. It does not provide detailed service descriptions, prices, availability or opening hours. This concept uses only the listed facts and asks visitors to confirm service details directly.

Source: [Stadt Kelsterbach — Branchen und Firmen](https://kelsterbach.de/Wirtschaft-Gewerbe/Branchen-und-Firmen/) (checked 16 October 2026).

## Pages

- `index.html` — location-focused overview and direct call path.
- `leistungen.html` — verified category and a transparent inquiry path; no unverified service claims.
- `kontakt.html` — publicly listed contact information and directions.

## Technology and local preview

Static HTML, CSS and a small vanilla JavaScript navigation toggle. No backend, tracking, external image, form, booking service, payment capability or third-party runtime is included.

Open `index.html` directly or serve this directory with any static web server. All internal links are relative and suitable for GitHub Pages project URLs.

## Deployment

The repository includes a GitHub Actions workflow that publishes the root static site to GitHub Pages. The live URL is recorded only after the deployment has been verified.
